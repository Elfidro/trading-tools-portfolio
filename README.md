Portfolio repository showcasing the architecture, design decisions, and select code samples from my automated trading systems built between 2023–2025 using Steam’s Web API and related platforms. # Trading Tools Portfolio

This portfolio repository highlights selected components from two personal projects:

- **Trading Multitool** — A system for data-driven trade analysis, price anomaly detection, and item crafting automation.
- **Personal Trading Bot** — A Node.js-based automation bot for handling trades, confirmations, and chat commands on the Steam platform.

> ⚠️ Note: This repo is for demonstration purposes only. Proprietary or sensitive logic has been redacted.

---

## 🛠️ Technologies Used

- **Languages:** Python, JavaScript (Node.js), Bash
- **Tools/APIs:** Steam Web API, JSON, Git/GitHub, Visual Studio Code
- **Data Handling:** Custom parsers, market data scrapers, structured trade logs
- **Deployment:** Raspberry Pi (for 24/7 uptime)
